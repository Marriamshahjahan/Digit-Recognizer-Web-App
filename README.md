# Digit-Recognizer-Web-App
Interactive handwritten digit recognizer built with HTML, CSS, JavaScript, and TensorFlow.js for real-time prediction of digits (0–9).


## 🚀 How to Run This Project Locally

This project uses TensorFlow.js and loads model files, so it must be run using a local server.

---

### 🔹 Option 1: Using Git (Recommended)

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Marriamshahjahan/Digit-Recognizer-Web-App.git
```

#### 2️⃣ Navigate to the Project Folder

```bash
cd Digit-Recognizer-Web-App
```

#### 3️⃣ Start a Local Server

If you have Python installed:

```bash
python -m http.server 8000
```

#### 4️⃣ Open in Your Browser

Go to:

```
http://localhost:8000
```

---

### 🔹 Option 2: Without Git (Download ZIP)

#### 1️⃣ Download the Project

- Go to the GitHub repository page  
- Click **Code**  
- Click **Download ZIP**

#### 2️⃣ Extract the ZIP File

Extract the downloaded ZIP file to your desired location.

#### 3️⃣ Open Terminal Inside the Extracted Folder

#### 4️⃣ Start Local Server

```bash
python -m http.server 8000
```

#### 5️⃣ Open in Your Browser

```
http://localhost:8000
```
